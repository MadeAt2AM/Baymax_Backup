# Hermes Project Rules

- This is the Competitors Intelligence Dashboard project.
- Read `IMPLEMENTATION_CHECKLIST.md` before any procedure. Mark a task complete only after objective verification, then update the checklist before the next task.
- Keep all project files under `/root/.hermes/projects/competitors/`.
- Use Asia/Singapore (SGT, UTC+8) first for timestamps and schedules; show UTC second only when reconciling source data.
- No Apify, ElevenLabs, Groq, OpenAI Whisper, or other paid scraping/transcription API calls. Scraping uses the approved OpenCLI Instagram method on the dev VPS; transcription uses local Faster-Whisper and FFmpeg on the dev VPS.
- Never expose or log cookies, session IDs, browser profiles, signed media URLs, passwords, API keys, or private transcripts.
- Do not bypass Instagram login challenges, checkpoints, rate limits, or platform protections.
- Use TDD for code changes: RED, verify failure, GREEN, verify pass, then refactor.
- Read-only diagnosis is the default on infrastructure. Destructive or disruptive VPS changes require explicit operator confirmation immediately before execution.
- Never declare a live fix from local tests alone. Verify the deployed user-visible path.
